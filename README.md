# Nxt Trendz – E-commerce Application

## Live Demo

**Visit Nxt Trendz - https://vinaysnxttrendz.ccbp.tech/login**

Nxt Trendz is an e-commerce web application inspired by Amazon, where users can log in, browse products, search and filter products, sort products, and explore an online shopping experience.

## Features

* User authentication with username and password.
* Prime and Non-Prime user login.
* Browse and view product listings.
* Search and filter products.
* Sort products based on available options.
* Protected routes for authenticated users.
* Responsive user interface.
* API integration to fetch product data.
* JWT-based authentication and authorization.
* React Router for navigation.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vinaysunkari30/E-Commerce-Application.git
```

### 2. Navigate to the Project Directory

```bash
cd YOUR_PROJECT_DIRECTORY
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm start
```

The application will run locally at the URL displayed in your terminal.
